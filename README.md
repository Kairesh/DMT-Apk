## 📲 How to Install

1. Download **DelhiMetroTracker.apk** using the link above.
2. Open the downloaded file on your Android device.
3. If prompted, enable **"Install from unknown sources"** for your browser.
4. Tap **Install** and enjoy instant, offline-first Delhi metro & bus navigation!

## 🔄 Automatic In-App Updates

Delhi Routes automatically queries this repository's `version.json` and `dtc_routes.json` on startup and via **Settings → Check for Updates**. When a newer build or bus route update is released, you will receive an instant 1-tap update prompt!
